# Tray Master Beta downloads

Approved Tray Master Beta installers and getting-started files will be available
in this repository's Releases when the beta is ready.

Visit [Tray Master downloads](https://www.traymaster.uk/downloads/) for availability
and installation guidance. Tray Master Beta runs on Windows x64. Individual beta
licence keys are supplied privately by the organiser.

Beta installers are currently unsigned. Windows may show an unknown-publisher or
unrecognised-app warning. Confirm that the file comes from the official download
link or your beta organiser. Keep Windows security protections enabled; contact
your organiser or IT administrator if installation is blocked.

Support: [betatest@traymaster.uk](mailto:betatest@traymaster.uk).
